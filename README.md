# Hi, I'm Ethan Webster
Front-end developer based in Port Orchard, WA, recently certified through
**Western Governors University** — coming to software from a hands-on technical career.
For years I ran machines and led crews in manufacturing and food-safety operations:
programming CNC laser systems, reading engineering blueprints to tight tolerances, and
supervising a 22-person sanitation team under USDA inspection. That kind of work runs on
precision, reliability, and staying level-headed when something breaks mid-shift — the
same habits I bring to writing and debugging code.
These days I build web apps with JavaScript and React, I'm expanding into TypeScript, and
Claude and Claude Code are part of how I get there — I'm working my way toward full-stack.

## How I Build

![Claude Code](https://img.shields.io/badge/Claude_Code-D97757?style=for-the-badge&logo=claude&logoColor=white)
Claude and Claude Code are part of my daily workflow, not a shortcut around learning. I use
them to talk through design decisions, get explanations for *why* an approach works before
I ship it, and speed up implementation on the parts I already understand — while I stay the
one making the architecture and logic calls. It's the same instinct from my manufacturing
days: use the right tool to move faster, but never stop understanding the machine.
